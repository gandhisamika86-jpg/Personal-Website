# Samika Gandhi | Personal Portfolio

Static HTML and CSS portfolio with project reports, images, presentations, and resume.

## Live updates

Vercel deploys the `main` branch automatically. Changes committed to this repository update the live portfolio after deployment succeeds.

## Structure

- `index.html`: homepage
- `projects/`: project pages and their assets
- `assets/`: resume and shared images
- `styles.css`: shared styling
- `resume.html` and `contact.html`: resume and contact pages

No build step or package installation is required. To preview locally, run `python -m http.server 8000` in this folder and open `http://localhost:8000`.
